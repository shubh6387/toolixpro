# 🚀 BoostHub: Standalone Social Growth Booster & Organic Optimizer

BoostHub is a premium, lightweight, standalone Single Page Application (SPA) designed to help content creators understand social media metrics, simulate audience campaigns, and optimize metadata (Titles, Descriptions, Keywords/Hashtags) for organic growth on **YouTube** and **Instagram**.

## ✨ Features

- **📊 Live Analytics Dashboard**: Connect mock channels and view real-time calculations of views, subscribers, followers, and engagement reach velocity.
- **⚡ Simulated Campaign Manager**: Allocate virtual credits to launch mock YouTube views/subscribers or Instagram followers/likes campaigns with active progress bars.
- **🪙 Traffic Credit Exchange**: Earn credits by interacting with community submissions inside an integrated **browser sandbox emulator** (e.g. mock viewing videos with timers or liking posts).
- **🔮 AI SEO Generator**: Input keywords or core topics to instantly generate high-CTR titles, description structures, and tagging configurations tailored for YouTube search algorithms and Instagram reels.
- **🎨 Premium Dark Theme**: High-performance UI designed with custom HSL dark variables, responsive grid flexbox, glassmorphic card overlays, and subtle pulse/glow micro-animations.

## 🚀 Quick Start (Running the App)

Because BoostHub is built with pure, standalone client-side technologies (HTML5, Vanilla CSS3, JavaScript ES6), there are **zero build setups** or `npm install` packages required to get started.

### Option 1: Direct File Open
Simply double-click on [index.html](file:///c:/Users/Shubham%20Tiwari/Desktop/toolnova/social-booster/index.html) (or right-click -> Open With) in your browser of choice (Chrome, Edge, Firefox, Safari) to run the application immediately.

### Option 2: Live Local Server (Recommended)
If you want to host it using a local development server, run one of the following commands in your terminal inside the `social-booster` folder:

**Using Node.js (`npx`):**
```bash
npx serve
```

**Using Python:**
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` (or the port specified by the server tool).
